火控方面：  
个人感觉纯手动检测弹丸数量非常吃发射机构状态，如双发、拨盘异常、限位寿命位置异常等  
最开始测效果最好，检测准确率能到90%以上(单发+连发)，最后只能达到75%，单发检测100%，连发只能在80%左右
曾经尝试过很多版：如何检测到一发弹丸打出来，  
如(摩擦轮+拨盘)电流检测、(摩擦轮+拨盘)速度检测、(摩擦轮+拨盘)加减速度检测、以及对应电流、速度、加减速度经滤波后的数据  
在处理单发时发现速度与加速度处理的效果远好于电流处理  
在连发处理时以上所有方法都不佳，尤其是滤波后的效果，远不如纯速度检测，其速度极性变乱甚至导致滤波后摩擦轮的数据会受到共振、拨盘转动的影响，并且滞后性极其严重

测试到后面由于发射机构某些器件寿命到了导致双发严重，同时存在延时双发问题，即单发模式下有双发同时双发之间有一段小间隔，在上一发发射后摩擦轮速度没回正时又发出一发，置于速度回到多少每次不确定；连发有明显的周期性：以每三发为一个周期不均匀弹频发射  
导致发射时摩擦轮速度、电流曲线非常抽象，观察上位机曲线几乎无法区分双发状态与单发状态：  
单发：每一发发射出来摩擦轮、拨盘速度修正所用时间不同、摩擦轮电流、掉速不同，保守策略只能采用检测拨盘状态，在弹丸满载的情况下问题不大；  
连发：明显看到每发弹丸之间用时不同，尤其是连发+双发问题，正常连发相同弹频下时间间隔差距不大，如此时加上双发导致时间间隔变乱，双发瞬间电流值幅值叠加，摩擦轮掉速持续时间差异大，唯一能用的保守策略仍然是用拨盘(连发这里没实际测过，类似于（当前位置-上一帧位置）看拨盘目标值增加的速度)
